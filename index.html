    ค้นหาเพลง หรือวางลิงก์ YouTube ด้านบนเพื่อเริ่มเล่น

    แนะนำให้ลอง

    ยังไม่ได้เลือกเพลง
     
    0:00-0:00
    เนื้อเพลง0.0s
    เนื้อเพลงจะขึ้นที่นี่

    ตั้งค่า

    YouTube API key (ไม่บังคับ ใส่แล้วการค้นหาเพลงจะเสถียรที่สุด ฟรี ทำครั้งเดียว)

    1. เปิด console.cloud.google.com แล้วล็อกอินบัญชี Google
    2. สร้างโปรเจกต์ใหม่ (ชื่ออะไรก็ได้) แล้วกด Enable ที่ "YouTube Data API v3"
    3. ไปที่ Credentials → Create credentials → API key แล้วคัดลอกมาวางด้านบน

    ถ้ายังไม่ใส่ key แอปจะลองค้นหาผ่านบริการสำรองให้ก่อน (อาจใช้ไม่ได้บางช่วง) และวางลิงก์เพลงหรือเพลย์ลิสต์เล่นได้ตามปกติ

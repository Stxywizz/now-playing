    Discord

    ต้องเปิดโปรแกรมตัวช่วยบนคอมค้างไว้ (ไฟล์ Start-Discord-Presence.bat) และเปิดแอป Discord แบบเดสก์ท็อป

    วิธีสร้าง YouTube API key
    1. เปิด console.cloud.google.com แล้วล็อกอินบัญชี Google
    2. สร้างโปรเจกต์ใหม่ (ชื่ออะไรก็ได้) แล้วกด Enable ที่ "YouTube Data API v3"
    3. ไปที่ Credentials → Create credentials → API key แล้วคัดลอกมาวางด้านบน

    ถ้าไม่ใส่ key ให้ติ๊กเปิดบริการสำรอง Piped ด้านบนแทน (ไม่เป็นทางการ อาจใช้ไม่ได้บางช่วง) การวางลิงก์เพลงหรือเพลย์ลิสต์เล่นได้ตามปกติโดยไม่ต้องใช้ทั้งสองอย่าง

    ภาพรวม

    สำรองและซิงก์

    สำรอง / กู้ข้อมูล

    เพลย์ลิสต์ เพลงที่ถูกใจ ประวัติ ค่าดีเลย์ที่จำไว้ และการตั้งค่า (ไม่รวม API key)

    ซิงก์อัตโนมัติระหว่างเครื่อง

    ทุกเครื่องที่ใส่รหัสเดียวกันจะเห็นข้อมูลชุดเดียวกัน (รหัสต่างกัน = คนละชุด) ข้อมูลถูกเข้ารหัสในเครื่องก่อนส่ง ต้องใส่ลิงก์ Worker ในแท็บ "การเชื่อมต่อ" และผูกที่เก็บ KV ไว้ก่อน เก็บรหัสเป็นความลับ ใครรู้รหัสก็เข้าถึงข้อมูลได้

    ย้ายข้อมูลไปอีกเครื่อง

    ส่งลิงก์นี้ให้ตัวเอง (เช่น Discord/LINE) แล้วเปิดบนอีกเครื่อง แอปจะถามว่าจะรวมเพลย์ลิสต์ ประวัติ และตั้งค่าเข้าไหม ลิงก์มีข้อมูลของคุณ อย่าส่งให้คนอื่น

    ระบบ

    โปรเจกต์ส่วนตัวเพื่อการทดลองและการศึกษา ไม่ได้เกี่ยวข้องหรือได้รับการรับรองจาก YouTube/Google วิดีโอเล่นผ่านเครื่องเล่นฝังอย่างเป็นทางการของ YouTube กด ? เพื่อดูคีย์ลัดทั้งหมด

    ใส่ / แก้เนื้อเพลงเอง

    วางเนื้อเพลง (บรรทัดละประโยค) หรือวางแบบ LRC ที่มี [00:12.34] นำหน้า แล้วเลือก "บันทึก" ถ้าเป็นเนื้อเพลงธรรมดา ให้กด "จับจังหวะ" เพื่อกดบอกว่าแต่ละบรรทัดเริ่มตอนไหนระหว่างฟังเพลง บันทึกไว้เฉพาะเพลงนี้ในเครื่องคุณ

    จับจังหวะ

    เพลงจะเริ่มเล่นใหม่จากต้น กดปุ่มด้านล่าง (หรือกด Space) ตอนที่นักร้องเริ่มร้องบรรทัดที่ไฮไลต์ ผิดให้กด Backspace ย้อน
